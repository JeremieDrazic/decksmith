# Screen Mocks

ASCII mocks defining the structure and layout regions of each screen (desktop + mobile). They are
intentionally low-fidelity — they capture composition and hierarchy, not pixel-level styling, which
lives in `packages/web-ui` and the design tokens.

- [Auth](./auth) — login, register, forgot password
- [Deck List](./deck-list) — deck overview and creation entry point
- [Deck Builder](./deck-builder) — sections sidebar + card grid + stats
- [Collection](./collection) — inventory grid/table/list, folders, tags
- [Card Search](./card-search) — global popover, `/search` page, deck builder slide-over
- [Card Detail](./card-detail) — card view, prints, 3D viewer
- [Settings](./settings) — account, preferences, appearance
